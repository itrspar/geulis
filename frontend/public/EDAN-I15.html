Manual Alat EDAN i15

Blood Gas & Chemistry Analyzer (analisis gas darah, elektrolit, dan kimia klinik) — integrasi ke GeuLIS

Identitas alat contoh (dari unit di lapangan): Instrument Name Blood Gas and Chemistry Analyzer · System ID M22311590014 · Software V1.79 / V1.73.
Perhatian kalibrasi: bila layar alat menampilkan “Calibrant Fluid Pack Expired, Invalid”, alat tidak mengeluarkan hasil yang sah sampai paket cairan kalibran diganti dengan yang belum kedaluwarsa. Hasil apa pun sebelum kalibran diganti tidak boleh dipakai untuk keputusan klinis.

1. Tentang alat & parameter

EDAN i15 adalah penganalisis point-of-care berbasis kartu uji (cartridge): satu sampel darah diteteskan ke kartu, alat membaca sejumlah parameter sekaligus. Parameter yang tersedia bergantung pada jenis kartu yang dipakai. Umumnya mencakup:

  • Gas darah: pH, PCO₂, PO₂
  • Elektrolit: Na⁺, K⁺, Ca²⁺, Cl⁻, Hct
  • Metabolit / kimia: Glukosa, Laktat, BUN/Urea, Kreatinin (sesuai kartu)
  • Terhitung: HCO₃⁻, TCO₂, BE, SO₂%, Anion Gap (diturunkan alat dari yang terukur)

Nilai terhitung dihasilkan alat, bukan diukur langsung. GeuLIS menyimpan angka apa adanya; interpretasi (rujukan/kritis) mengikuti katalog pemeriksaan di GeuLIS.

2. Koneksi ke GeuLIS

i15 mengirim hasil ke LIS lewat jaringan (Ethernet/Wi-Fi) memakai protokol HL7. Arah komunikasinya: alat yang menghubungi LIS (alat sebagai pengirim), jadi di GeuLIS alat didaftarkan dengan mode “Alat menghubungi LIS” dan GeuLIS mendengarkan pada satu port.

SetelanNilai
ProtokolHL7 (v2, ORU^R01)

Nomor sampel di alat harus persis sama dengan No. Order permintaan di GeuLIS. Kalau berbeda, hasil tetap tersimpan tapi berstatus “belum cocok” dan harus dicocokkan manual.

3. Setelan LIS di alat

Pada layar EDAN i15 (jalur menu bisa sedikit berbeda antar versi firmware — konfirmasikan di alat):

  1. Masuk Setup / Settings → Communication (atau LIS/HIS).
  2. Aktifkan pengiriman ke LIS dan pilih protokol HL7.
  3. Isi Server IP = alamat server GeuLIS, dan Port = port listener GeuLIS.
  4. Aktifkan Auto Transmit / Auto Send agar tiap hasil otomatis terkirim.
  5. Simpan, lalu jalankan satu sampel uji untuk memastikan hasil masuk ke GeuLIS.

4. Alur kerja

  1. Daftarkan alat di GeuLIS: menu Alat Laboratorium → tambah alat, protokol HL7, mode “Alat menghubungi LIS”, port sesuai setelan di atas.
  2. Petakan kode parameter alat (pH, Na, K, Glu, …) ke pemeriksaan GeuLIS lewat mapping alat. Kode yang belum dipetakan tetap tersimpan dan menunggu dipetakan (tidak hilang).
  3. Petugas memberi No. Order sebagai Sample ID di alat, lalu menjalankan sampel.
  4. Hasil masuk otomatis ke GeuLIS, tercocok ke permintaan, lalu diverifikasi petugas sebelum dirilis.

5. Pemecahan masalah

GejalaKemungkinan sebab & tindakan
Pesan masuk tapi Parameter 0 / “identitas tidak dikirim alat” Alat mengirim pesan (mis. registrasi/keepalive) tanpa segmen hasil (OBX), atau formatnya belum dikenali. Pastikan alat diset mengirim hasil (bukan hanya sampel), protokol HL7 benar, dan kode parameternya sudah dipetakan di GeuLIS.
Hasil “belum cocok” Sample ID di alat ≠ No. Order GeuLIS. Samakan penomorannya, atau cocokkan manual di menu Hasil Belum Cocok.
Calibrant Fluid Pack Expired, Invalid Paket cairan kalibran kedaluwarsa — ganti dengan yang baru. Alat tidak memberi hasil sah sampai diganti.
Alat tidak terhubung Periksa kabel/Wi-Fi, IP server & port benar, dan server GeuLIS mendengarkan di port itu (uji dari alat: kirim satu sampel).

Dokumen ini panduan integrasi GeuLIS, bukan pengganti manual resmi EDAN. Untuk pengoperasian, kalibrasi, dan keselamatan alat, ikuti manual pabrikan. Hasil wajib diverifikasi tenaga laboratorium berwenang.
