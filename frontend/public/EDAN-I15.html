1. Cara alat terhubung ke GeuLIS

Alat yang menghubungi GeuLIS. Di Network Setup yang diisi adalah alamat server GeuLIS. GeuLIS menunggu di port 8000. 

EDAN i15 192.168.9.105  ──menghubungi──▶  GeuLIS 192.168.9.106:8000
                        ──kirim hasil HL7 (ORU^R01, MLLP)──▶
                        ◀── ACK^R01

Framing pesannya MLLP (0x0B ... 0x1C 0x0D). Protokol yang dipakai adalah HL7 v2.4.

Alat menyediakan dua protokol: HL7 v2.4 dan POCT1-A. Pakai HL7 — GeuLIS belum berbicara POCT1-A.

4. Yang diketik petugas di alat

Di layar Enter Patient Information ada beberapa field. Yang menentukan pencocokan ke order adalah Sample ID — bukan Patient ID.

Nilai Sample ID harus sama persis dengan medical_record_no, order_no, request_no, atau simrs_order_id di GeuLIS. Kotak Sample ID EDAN panjang (sampai ~22 karakter) — nomor order SIMRS muat.

ICU rutin AGD berkali-kali sehari pada pasien yang sama. Kalau petugas mengetik nomor rekam medis, GeuLIS memilih order pasien itu yang terbaru — hasil pagi bisa nyantol ke order sore. Untuk analisa gas darah, ketik atau scan nomor order SIMRS (tiap order unik) — jangan nomor RM.

Paling aman: scan barcode label tabung (EDAN mendukung scanner Honeywell 1900). Pastikan barcode di label = nomor order.

5. Parameter & pemetaan

Jenis pemeriksaan ditentukan oleh kartrid (BG3/BG8/BC4/BG9-Lac, dsb). Alat mengirim parameter terukur dan puluhan parameter hitungan. Yang sudah dipetakan di GeuLIS:

JenisParameter (kode alat)
Terukur — ada rentang rujukan (dari OBX-7 pesan alat) Na+, K+, Ca++, Cl-, pH, pO2, pCO2, Hct
Terukur — rujukan kosongGlu, Lac
Hitungan — rujukan kosongHCO3-act, HCO3-std, BE(ecf), BE(B), ctCO2, sO2(est), tHb(est), mOsm, cH+, BB(B)
Rentang rujukan 8 parameter terukur diambil dari konfigurasi alat supaya flag GeuLIS sama dengan flag di layar alat — bukan angka karangan, tapi tetap perlu dikonfirmasi lab. Parameter hitungan sengaja dikosongkan; nilai kritis semua kosong.

Parameter terkoreksi suhu (pH(T), pO2(T), dst), rasio a/A, dan RI tidak dipetakan. Nilainya tetap tersimpan (tanpa pemeriksaan tujuan) dan bisa dipetakan lab bila diperlukan.

6. Kekhasan pesan EDAN

MSH|^~\&|EDAN|i15^<serial>|LIS||<waktu>||ORU^R01||P|2.4||||0||UNICODE UTF-8||||
PID|||<patient id>|||||M
OBR|||<sample id>|EDAN^i15|||<waktu tes>||||||||Arterial|<operator>
OBX|0|ST|0|Na+|141|mmol/L|138^146||...        ← OBX-3=0 terukur, nama di OBX-4
OBX|5|ST|1|tHb(est)|15.5|g/dL|2.9^27.7||...    ← OBX-3=1 hitungan
OBX|7|ST|2|Temperature|37.0|℃||...              ← OBX-3=2 info pasien, DILEWATI
  • OBX-3 hanya angka tipe — 0 = parameter terukur, 1 = hitungan, 2 = info pasien (Temperature, FIO2). Nama parameter sungguhnya ada di OBX-4. Baris tipe 2 tidak disimpan sebagai hasil. Parser sudah menangani.
  • Pembeda QC ada di MSH-16: 0 = hasil pasien, 1 = kontrol, 2 = verifikasi kalibrasi.
  • OBX-2 selalu ST walau nilainya angka. OBX-7 = rentang rujukan format bawah^atas. OBX-8 = flag (kosong / ↑ / ↓).
  • Sample ID di OBR-3 (posisi standar). Patient ID di PID-3. Petugas mengetik keduanya di layar "Enter Patient Information" saat menjalankan tes.
Karakter ↑ ↓ ℃ pernah menggagalkan penyimpanan hasil. Kolom raw_message/raw_data dulu berformat latin1 sehingga karakter ini membuat INSERT ditolak dan hasil pasien hilang tanpa jejak. Sudah diperbaiki — kolom dikonversi ke utf8mb4 otomatis tiap backend start. Kalau muncul lagi setelah pindah server/DB, jalankan ulang ensureSchema.
Kiriman riwayat. Saat koneksi pertama dinyalakan, alat membuang hasil lama di memorinya ke GeuLIS (sudah terjadi: 2 sampel lama). Semua mendarat di Hasil Belum Cocok.

7. Kontrol mutu

Hasil kontrol EDAN dikenali lewat MSH-16 (1 atau 2) dan dipisahkan dari hasil pasien. Kalau lab ingin dinilai dengan aturan Westgard di modul QC GeuLIS, daftarkan lot kontrol beserta mean/SD lebih dulu — tanpa itu, nilai tetap disimpan dengan verdict unknown.

Jenis sampel yang bisa dipilih di alat: Arterial, Venous, Mixed Venous, Capillary, Aqueous, CPB.

8. Kalibran kedaluwarsa & mode simulasi

Status bar alat menampilkan "Calibrant Fluid Pack Expired, Invalid" — tes pasien sungguhan terblokir sampai kalibran diganti (menu Setup › Replace Cal Pack, scan barcode kalibran baru).

Untuk latihan alur sebelum kalibran baru datang:

  • DEMO Test — logout, login dengan username & password keduanya demo. Menjalankan simulasi penuh dengan hasil karangan tetap. Tidak butuh darah.
  • Internal Simulator — menu Setup › Test Setup › Internal Simulator.
Data DEMO/simulator belum tentu ikut dikirim ke LIS — banyak alat sengaja mengecualikannya. Kalau tidak muncul di Log Alat, itu wajar; uji sungguhan tetap perlu setelah kalibran diganti.
